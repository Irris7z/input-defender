## Mac / iOS Safari版の開発プロジェクト

- iOS 26以降のSafari Web Extensionと、有効化手順・プライバシー・監視範囲を表示するiPhone/iPadアプリを追加しました。拡張ロジックはChrome版と共有します。
- macOS 15.4以降・Safari 26以降向けのMacアプリとSafari拡張も追加しました。Apple Silicon / Intelのユニバーサルビルド、拡張の有効化状態の確認、Safari設定への導線を用意しました。
- iOSで利用できないwebRequestをSafari版から外し、画像・Worker・リダイレクトなど通信全体の観測が対象外であることを表示します。フォーム・構造・対応するページ内送信APIの監視は継続します。
- メモリ内の記録と端末内設定を維持し、ネイティブアプリへの閲覧情報の転送・ログ出力は行いません。
- 送信API監視の設定受領ハンドシェイクを追加し、起動未確認の場合を表示します。
- Xcodeプロジェクト、ビルド・テストコマンド、Safari向け互換性テスト、iOS WebKitの検知・停止テストを追加しました。
- 検知テストをMac / iOSで共有し、Macの案内画面の描画テストを追加しました。Actionsでも両プラットフォームのビルド・WebKitテストに成功した場合だけChrome版をリリースします。

このリリースの拡張用ZIPは引き続きChrome用です。Mac / iOS版はXcode開発プロジェクトであり、Safari本体の権限・復帰動作などの検証、Appleの署名、配布手続きが別途必要です。Developer IDでの署名・公証、TestFlight / App Store公開は行っていません。
