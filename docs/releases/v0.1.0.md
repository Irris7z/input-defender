# Input Defender v0.1.0

入力値を読まず、サイトのフォームと通信の挙動から不審な動きを警告するChrome拡張の初回リリースです。

## 導入

1. Assetsから **input-defender-0.1.0.zip** をダウンロードし、フォルダに展開します。
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開した `manifest.json` が入ったフォルダを選びます。
4. 対象ページを再読み込みします。

Chrome 119以上が対象です。Chrome Web Store版ではありません。GitHubの自動生成ソースアーカイブではなく、上記の拡張用ZIPを使用してください。

## 機能

- 個人情報用フォームの外部送信先、送信先の変更、暗号化されない送信先を検知。
- 個人情報用の欄への入力直後の外部通信を、通信本文に触れずに観測。
- 要注意の動きはページ内警告、検知記録は拡張アイコンから確認。
- 初期設定は「検知のみ」。対応する送信処理を停止するモードは任意。
- 通知除外、記録の絞り込み、影響範囲を示す削除確認。
- 状態・監視モード・画面切り替えの位置を固定した日本語UI。

## プライバシーと検知の限界

入力値・通信本文・Cookie・ヘッダーを取得しません。外部判定サービスやテレメトリーはありません。検知記録はブラウザのメモリ内、設定はこの端末だけに保存します。

警告は挙動に基づく推定であり、漏えい・改ざん・悪意を断定しません。正規の決済や住所補完でも警告する場合があります。同じ送信先へのHTTPS通信などの見逃しや、ページ側による監視の妨害があり得ます。完全な検知・遮断を保証するものではありません。

## 検証

単体・プライバシーテスト13件と、拡張の実読み込みを含むブラウザテスト11件。通常表示、縮小表示、Chrome本来の拡張ポップアップのサイズと主要操作も確認しています。

配布ZIPの整合性は、添付の `SHA256SUMS.txt` で確認できます。
