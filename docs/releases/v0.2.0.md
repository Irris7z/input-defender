## 入力前のサイト構造分析

- 入力操作を待たずに、フォームの送信先・送信方法、個人情報用の欄、外部スクリプトと埋め込み先を自動で調べます。
- 「サイト構造」タブに、オリジン・カテゴリ・件数だけの一覧を追加しました。
- GET設定の個人情報用フォームはWARNING、新しい外部スクリプト参照元はCRITICAL、新しい外部埋め込み先はWARNINGで通知します。フォーム送信先変更のFATALは継続します。
- フォーム外に関連付けられた欄、送信ボタンの送信方法上書き、base要素による送信先変更を扱います。GET設定は対応するフォームの送信時に停止モードの対象になります。
- 構造分析はISOLATED worldで動きます。MAIN worldのAPIフックが上書きされても独立してDOM属性を観測します。
- 外部参照の存在やintegrity属性の欠如だけでは悪意と判定しません。構造変更の観測はスクリプト実行前の遮断を保証しません。
- 入力値・通信本文・HTML全体・スクリプト本文は取得しません。外部接続・追加権限なし。
- 空欄のまま試せるローカル検証ページ `structure-lab.html` とブラウザテストを追加しました。
