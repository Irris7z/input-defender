# Input Defender v0.1.1

HTTPの警告によって、自動送信の疑いやフォーム送信先の変更が隠れる問題を修正しました。

- 該当する検知理由をすべて記録し、ページ内警告と拡張の検知記録に個別の見出し付きで表示します。
- HTTP警告の直後でも、新しい挙動を検知したら通知を追加します。
- ページ内通知は種類ごとに積み重ね、FATAL（紫）→ CRITICAL（赤）→ WARNING（黄）の順に表示します。同じ種類・元ページ・送信先の繰り返しは通知受信回数にまとめます。
- 深刻度はWARNING（HTTP・外部フォーム）、CRITICAL（入力直後の外部送信・通信・転送）、FATAL（フォーム送信先の変更）の3段階です。FATALでも漏えいや悪意の確定ではありません。
- HTTPと外部リダイレクトの理由も同時に保持します。
- 通常の送信ボタンを使ったフォーム送信でも、元フォームの送信先変更を維持して判定します。
- 入力値・通信本文を取得しない設計と、通知除外・停止モードを維持しています。

検証には `npm run demo` で起動する `http://127.0.0.1:4173/attack-lab.html` を使用できます。初期値のダミーだけで試してください。

拡張用ZIPを展開して読み込み、拡張と対象ページを再読み込みしてください。

単体・プライバシーテスト18件とブラウザテスト15件で、通知の優先順、指定色、重複集約、閉じる操作、送信停止、入力値の非保存を検証しています。配布ZIPの整合性は添付の `SHA256SUMS.txt` で確認できます。
