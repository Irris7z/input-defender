Input Defender · 危険挙動のローカルテスト

ダミー情報を読み取って送信する、テスト専用のページです。

本物の個人情報は入力しないでください。

このページのテストコードは入力値を読み取ります。拡張本体は読み取りません。送信先はこの端末の 127.0.0.1:4174 に限定し、受信した値は保存せず破棄します。

ローカルサーバーから開いてください

npm run demo を実行し、http://127.0.0.1:4173/attack-lab.html をChromeで開きます。ファイルを直接開いた場合、テスト操作は無効です。

先に拡張を有効にしてください。「検知のみ」と「要注意の送信を停止」で結果を比較できます。このページはHTTPのため、開いた直後から暗号化されないフォームの警告が出るのは想定どおりです。

通知は上からFATAL（紫）→ CRITICAL（赤）→ WARNING（黄）の順です。フォーム送信先の変更はFATAL、入力直後の外部送信はCRITICAL、HTTPはWARNINGとして、別々の通知に表示されます。漏えいや悪意の確定を意味する深刻度ではありません。

1 · ダミー情報を用意

テスト用フォーム

初期値のまま試せます。入力直後の検知を試すときは、どれかの欄を実際に編集してください。

送信先: 127.0.0.1:4173（元の送信先）

別ポートの 4174 を、悪意ある外部サイトの代わりに使います。

2 · 危険な動きを実行

検知する挙動を選ぶ

入力中に、送信ボタンを押さずに送る 停止中

開始後に左の欄を編集すると、値を読み取り、少し遅れて自動送信します。最も分かりやすいテストです。

入力値を手動で読み取って送る

直前に欄を編集し、5秒以内に押してください。手段ごとの警告・停止を確認できます。

フォームの送信先を後から差し替える

「送信先を改ざん」は変更だけを行います。実際の送信は隣のボタンで試します。

3 · 結果を確認

このページの実行結果

送信処理の結果だけを表示し、入力値はログに出しません。警告理由や停止記録は拡張アイコンの「検知記録」で確認してください。
